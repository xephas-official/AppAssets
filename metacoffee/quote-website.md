## Complexity assessment

**Medium–High.** This is not a brochure site. It is a custom e-commerce platform with a multi-step order flow where each choice changes the next set of options (country → coffee → roastery → roaster), a pricing engine, online payments, delivery scheduling, and an admin side to manage it all.
